# Design Source

Canonical brand and design files live in:

https://github.com/itscjarienza/cj-brand-systems/tree/main/nodysseus

Before making visual, brand, social, or website changes for Nodysseus, read these files from the canonical brand repo:

1. `nodysseus/DESIGN.md`
2. `nodysseus/BRAND-IDENTITY.md`
3. `nodysseus/BRAND-BRIEF.txt`
4. `nodysseus/SERVICES.md` when offer or service language matters
5. Relevant files in `nodysseus/assets/`

This repository is the website implementation repo. Do not treat copied design files here as canonical.
